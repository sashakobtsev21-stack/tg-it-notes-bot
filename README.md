# tg-it-notes-bot

Автоматизация конвейера для Telegram-канала IT_Notes: сбор новостей → отбор → черновик поста → вычитка в личке → публикация.

## Статус

Сделан только сбор (шаг 1 из 5). Дальше по порядку: дедуп + отбор (скоринг), черновик текста, бот с кнопками для вычитки, публикация.

## Как запустить сбор

```
npm install
npm run collect
```

Печатает в консоль список свежих новостей из GitHub Releases отслеживаемых репозиториев и Hacker News (без ключей — оба источника бесплатные и открытые).

## Источники (пока)

- **GitHub Releases** — список репозиториев в `src/config/sources.js`
- **Hacker News** — поиск по ключевым словам через открытый Algolia API

Официальные блоги лабораторий (Anthropic/OpenAI/Google) добавлю следующим шагом — там у части нет прямого RSS, нужно сверить точные адреса, чтобы не подсунуть мёртвую ссылку.
